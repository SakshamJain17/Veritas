# VERITAS contracts

These Solidity files define the intended EVM registries for documents, claims, issuers, and verification events. They are source examples only: the local app does not compile, deploy, or call them. The UI and API use a clearly labeled simulated demo network.

The design stores commitments and issuer identifiers rather than document files. A production deployment still needs contract tests, access-control review, deployment scripts, chain configuration, wallet integration, and an independent security audit before use.
